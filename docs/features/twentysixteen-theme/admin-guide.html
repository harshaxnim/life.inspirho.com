Maintaining ins · Π · rho

The blog is a set of files in this repository. GitHub Pages turns them into the site every time a change is pushed. There is no administration screen.

Adding a post

Create _posts/YYYY-MM-DD-short-name.md. Write the post in Markdown or HTML under a header like this:

---
layout: post
title: My new post
categories: [cg]
permalink: /cg/my-new-post/
subtitle: <p>One line shown under the title</p>
---

The post then appears on the home page, in its category and on the All page.

Changing the menu

Edit _data/menus.yml. primary is the menu at the top and bottom of every page. social is the list of social links, and its icons are chosen from each link's address.

Posts per page on the home page

Change paginate: 5 in _config.yml.

Moving to another domain

Change the CNAME file and url: in _config.yml together, then update DNS as the README describes.

Checking a change before publishing

Run the preview command from the README and open http://localhost:4000.
